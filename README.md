# 照骨镜：汴京失物案

> 一面镜子，三个都说是它的人。你只有一盏灯的时间，找出它真正记得的人。

一个**国风互动推理小游戏**：用「光检 · 听音 · 拓印」三种古代鉴物手法，调查一面宋风铜镜，在三名认领者中推理出它真正的主人。

既可**离线打包成小红书小工具**，也有 **GitHub Pages 在线版**。

**🕹️ 在线体验：<https://better6666.github.io/zhaogujing-bianjing-mystery/>**

## ✨ 玩法亮点

| 鉴物手法 | 玩法 | 你能发现什么 |
| --- | --- | --- |
| 🔦 **光检** | 移动灯光扫过镜背 | 三处被岁月藏起的痕迹：磨损的双羽纹、镜缘朱漆、二次打磨的裂口 |
| 🎵 **听音** | 记住镜体被敲击的四声回响 | 用「玉磬 / 木鼓 / 铜钲」复现「清·暖·沉·清」的曲牌节奏 |
| 🖨️ **拓铭** | 按纸拓印被锈蚀遮住的铭文 | 「湖州石家青铜照子」——作坊来处 |
| ⚖️ **推理** | 指出你最信任的证物 | 作坊铭 ≠ 物权证明，使用痕才指向真正的主人 |

- 🏆 **多结局 & 鉴物评分**：三名嫌疑人对应三种结局，满分为「特级照骨官」
- 🥇 **隐藏成就**：「过耳不忘」（听音一次过）、「纤毫毕现」（拓满十二区）
- 🥚 **封面彩蛋**：连点镜心「玄」三次，镜中会浮现一句暗语
- 🔊 **音效 / 震动 / 提示**：全程 WebAudio 实时合成音效（无需任何外部资源），卡住随时点顶部「提示」
- 📱 **移动优先**：适配手机与桌面，支持安全区与「减少动效」系统设置

## 🎮 玩法流程

1. **接下奇案** → 阅读开封府快报，了解三名认领者
2. **光检** → 移灯找到镜背 3 处痕迹
3. **听音** → 先「听回响」，再用三种器物复现四声顺序
4. **拓铭** → 按住拓纸扫过空白区域，读出 12 区铭文
5. **推理** → 选择镜主人 + 你最信任的证物，落下结案印
6. **结案** → 揭晓结局、鉴物评分与成就称号

## 🛠️ 技术栈

- **在线版**：Next.js 16 · React 19 · Tailwind CSS 4（`app/`，经 `vinext` 工具链构建）
- **小红书小工具**：原生 HTML/CSS/JS 单文件离线包（`小红书最终兼容上传包/`），纯本地、不联网、所有资源打包在内

## 📜 史实边界

「玄羽镜」、沈七娘等人物、宣和四年失物案及全部对话均为**虚构**。宋代铜镜的形制、镜钮、纹饰、作坊铭记与拓片研究方法，参考了上海博物馆、故宫博物院、中国国家博物馆的公开馆藏资料；「四声曲牌暗号」为游戏机制，非历史考证结论。
